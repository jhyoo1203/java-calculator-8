# 🧮 문자열 덧셈 계산기

---

## 📌 기능 단위 구분

- [ ] 구분자 등록
    - 생략 가능 - default: 쉼표, 콜론
- [ ] 더하기 기능
    - 순서 보장 필요 X
    - 빼기, 곱하기 등 추후 추가될 수 있는 로직에 대한 확장성을 고려한 설계
- [ ] 구분자 등록 문자열과 더하기 문자열을 구분하는 기능

---

## ⚠️ 검증

- [ ] 양수 숫자 input
- [ ] 커스텀 구분자 등록인가?
    - prefix: `//`, postfix: `\n`
- [ ] 끝 부분이 숫자가 아닌 값으로 끝날 경우
- [ ] 문자열 max length
- [ ] 숫자 최대값 검증
- [ ] 숫자가 입력으로 들어오지 않을 경우
- [ ] **(중요)** 빈 문자열은 0으로 출력되어야 함
    - 고려사항: 공백 문자도 0으로 출력할것인가?

---

## ⭐️ 도메인 설계

- TargetNumbers
    - 계산을 진행할 숫자들
    - 일급 컬렉션
    - 항상 다건 동시에 등록 예정이기 때문에 검증도 여기서 처리
- Delimiters
    - 구분자 일급 컬렉션 객체
    - default로 `,`, `;`가 static 하게 추가되어 있음
    - 현재 커스텀 구분자는 단건 등록이지만 다건으로 확장 쉽게 설계 
- Delimiter
    - 구분자 객체
    - 검증 여기서 처리
